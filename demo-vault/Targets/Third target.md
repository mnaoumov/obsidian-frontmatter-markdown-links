# Third target

A link target reached from exactly one place: the `seeAlso` property of [02 Backlinks](<../02 Backlinks.md>), a value holding **several links**. Obsidian does not count a link inside such a value as a backlink by itself, so whether `02 Backlinks` shows up in this note's **Backlinks** pane depends on `Frontmatter Markdown Links` alone.
